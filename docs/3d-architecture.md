# 3D Architecture

**Stack:** Three.js + React Three Fiber + Drei

## Scene
Night environment, fog, moon, particles, central Security Temple, radial chambers (Auth, API, Database, Access Control, JWT, Final Core), glowing Security Core, interactive doors.

## Chambers unlock progressively based on user progress.

## Performance
- GLB assets, instancing, LOD, quality tiers (High/Medium/Low/2D fallback)
- prefers-reduced-motion support
- Target 60fps on mid-range laptops
