# Challenge Architecture

## Learning Loop
MISSION → OBSERVE → HYPOTHESIS → TEST → DISCOVER → UNDERSTAND → FIX → VERIFY

## Roadmap
1. Weak Authentication
2. NoSQL Injection
3. XSS (Reflected + Stored)
4. IDOR
5. JWT Security
6. API Security
7. Database Security
8. RBAC
9. Final Boss (composite)

## XP
Discovered +100 | Understood +100 | Fixed +200 | Completed +300

## Levels
Novice → Explorer → Defender → Security Engineer → Cyber Guardian

## Labs structure
```
labs/
  auth/  nosql-injection/  xss/  idor/  jwt/  api-security/
```
Each with Dockerfile, src, tests, seed, README.

Challenges are data-driven from backend. No hardcoding in frontend.
